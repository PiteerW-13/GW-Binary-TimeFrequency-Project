# Computational Simulation and Analysis in Orbital Evolution and Time-Frequency Morphology of Gravitational Waves from Compact Binary Systems

Author:
Peter Zhuo Xi Wu

Constructor University

## Research Question

How does orbital evolution of compact binary systems shape the time-frequency morphology of gravitational-wave signals?

## Project Goals

- derive simple waveform models
- simulate circular binaries
- simulate inspiral chirps
- produce spectrograms
- compare different binary systems
